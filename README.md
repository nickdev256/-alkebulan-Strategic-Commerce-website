# Alkebulan Global — Strategic Commerce Website

The website for Alkebulan Global, connecting African enterprises with global
trade, sourcing, and strategic partnership opportunities.

Built with React and Vite.

## Run it

```bash
npm install
npm run dev      # local preview at http://localhost:5173
npm run build    # production files in dist/
npm run lint
```

## Where things live

| What | File |
| --- | --- |
| Menu links (header, footer, page tabs) | `src/navigation.js` |
| Shared wording: sectors, services, advantages, contact email | `src/content.js` |
| Colours, fonts, buttons, cards, animations | `src/index.css` |
| Pages | `src/pages/` (each page has its own `.jsx` and `.css`) |
| Shared parts: header, footer, banners, icons | `src/components/` |
| Logo, emblem and icons | `public/images/`, `public/favicon.png` |
